# 走位用每個人的出發和到達，沒設的人最後一個八拍才走

原本兩張站位之間，每個人用整段時間慢慢直線走。教練要讓人站著不動，只能在中間多插站位、一張一張拖回去。現在改成：兩張站位之間，每個人最多走位一次。他的出發和到達存在後面那張站位上。沒設的人先站著，最後一個八拍才走。這樣「站著不動」不用另外做，跑翻這種一個接一個走的也做得到。

## Considered Options

- **只靠多插站位**（例如按「跟上一張一樣」）：不用改檔案格式。缺點有三個：站位會變很多；之後改了位置，人會在中間那張突然轉彎；往後帶也帶不過去，因為中間那張記的是半路的位置，跟舊位置不一樣。
- **每張站位只設一個「走幾拍」**：簡單，但做不到「有人先走、有人後走」。
- **沒設的人整段走（跟以前一樣）**：舊檔走法不變，但「一直跑」的問題還在。

## Consequences

- 流程檔升到第 2 版。舊檔打開後位置不變，但什麼時候走會變：先站著，最後一個八拍才走。
- 插站位時，正在走的人的走位要切成兩段，才能保證其他人的走法不變。
