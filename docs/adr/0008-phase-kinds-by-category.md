# 環節的種類跟著大類走，拿掉整體

以前環節有五種：上法、中段、轉接、下法、整體，哪個大類都能選哪一種。拋投、騰翻多半選「整體」，教練每次都要想「拋投該選整體還是上法」。成功率也會因為選法不同，分成兩堆。

現在改成：每個大類只能用自己的種類。

| 大類 | 能用的環節種類 |
| --- | --- |
| 技巧、金字塔 | 上法、中段、轉接、下法 |
| 拋投 | 只有拋法（從 dip 到接住一起算） |
| 騰翻 | 只有翻法 |
| 跳躍 | 只有跳法 |
| 舞蹈、其他 | 沒有環節，不記成功率 |

「整體」拿掉了。誰算一組、誰一個人一組，還是照大類決定：騰翻、跳躍一樣每個人自己算，也不用選組。

## Considered Options

- **每個大類只能用自己的種類，拿掉整體（選這個）**：教練不用想要選哪一種，成功率也不會分成兩堆。缺點是流程檔要升版，舞蹈、其他的舊紀錄會被拿掉。
- **整體留著，只給跳躍、舞蹈、其他用**：不會刪到資料。但「整體」這個詞還是含糊，跳躍跟騰翻的規則也不一致。
- **拋法照樣加，但哪個大類都能選**：改動最小。但拋法跟整體一樣在算拋投，教練還是要猜選哪個。
- **舊檔只換拋投，其他不動**：最不會改到資料。但舊檔會留著新規則不允許的種類，編輯器要多一套「舊的可以看、不能新增」的例外。
- **有環節時不讓換大類**：最簡單、不會改到資料。但現在從騰翻換成技巧時，本來就會自動重新分組。換大類時跟著換種類比較一致，按「復原」也拿得回來。

## Consequences

- 流程檔升到第 11 版。開舊檔時照大類換種類：拋投都換成拋法，騰翻都換成翻法，跳躍都換成跳法，技巧、金字塔的整體換成中段。名字和紀錄都留著。舞蹈、其他的環節和紀錄會拿掉（見 `docs/flow-file-format.md`）。
- 換大類時，環節換成新大類的種類，名字和紀錄都留著；換到技巧、金字塔都變上法。換到舞蹈、其他就拿掉環節；有紀錄的話先問，按「復原」紀錄會回來（ADR 0007）。
- 拋投、騰翻、跳躍只有一種環節可以用，拍點小窗直接寫好種類，不給選。舞蹈、其他沒有「環節」那一排。
