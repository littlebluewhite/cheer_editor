# 金字塔的環節可以佔同樣的拍，其他大類不行

以前同一個動作裡，環節標的拍不能重疊：標拍蓋到別的環節，就把別的切掉。金字塔不是這樣做的：第一個三層已經停在上面（中段），第二個三層才在上（上法），兩個環節同時在發生。教練沒辦法照實標。

現在改成：大類是金字塔的動作，環節可以佔同樣的拍，疊一部分或整段一樣都可以。技巧、拋投、騰翻、跳躍照舊，不能重疊。還是同一個動作、同一份環節清單，每一組記的環節都一樣。

跟著改的規則：

- **標拍**：金字塔裡標拍不會動到別的環節，各標各的。標過頭要自己把那個環節重標。其他大類照舊，蓋到就切掉。
- **打 ✗ 之後**：以前是「✗ 後面的環節空著」，後面就是清單上排在後面的。現在照拍算：✗ 的環節做完之後才開始的環節空著。跟它佔同樣拍的環節是同時在做的，還可以打記號，沒打就當空著。環節沒重疊時，結果跟以前一樣。
- **口號段**：不數拍，說不出誰跟誰同時，照舊（✗ 後面的都空著）。
- **換大類**：金字塔有環節疊著時，換成別的大類會被擋下來，要先把疊著的分開。
- **畫法**：疊著的環節往下多一排，跟拍點一樣。點哪一條就改哪一條。

## Considered Options

- **只有金字塔可以疊（選這個）**：只有金字塔會有好幾個上層同時做不同的事。技巧的每一組做的事一樣，開放了反而容易標錯。缺點是標拍有兩套規則（金字塔各標各的，其他蓋到就切）。
- **拆成兩個動作**：規則不用改。但一座金字塔的成功率會分成兩堆，整次成功率也看不出整座做得怎樣。
- **每一組有自己的環節**：最貼近「這幾個人在中段、那幾個人在上法」。但紀錄、成功率、練習畫面和流程檔的形狀都要改，改動最大。
- **每個大類都可以疊**：規則只有一套。但技巧是一個環節接一個環節標，蓋到就切掉比較順手，疊起來多半是標錯。
- **金字塔照舊會切，另外加一顆「疊上去」**：連著標比較順。但多一顆按鈕、多一件要解釋的事，「各標各的」比較好記。
- **✗ 之後照舊全部清空**：記一次的規則不用改。但同時在做的環節會被清掉，教練明明看到第二個三層上去了，卻不能記。

## Consequences

- 流程檔升到第 14 版。資料不用動（舊檔沒有重疊的環節），但舊版的程式打不開第 14 版的檔（見 `docs/flow-file-format.md`）。
- 「後面的環節」不再看清單上的先後，照拍算。練習的卡、全上的表、改一次，都用同一條規則。
- 拍點格子、八拍表、泳道的環節會變成好幾排（疊幾層就幾排）；流程影片本來就會分排。
- 選的拍剛好是兩個環節的拍時，不能再靠「拍一樣」認出要改哪一個，要記住點的是哪一條。
