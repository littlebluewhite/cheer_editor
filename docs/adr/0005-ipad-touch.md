# iPad 用手指編：沒選中的東西，手指一滑是捲畫面；選中了才拖得動

教練要在 iPad 上編流程，只用手指，沒有鍵盤。泳道、站位縮圖列、拍點格子上排滿了拖得動的東西。手指一碰到就開始拖，畫面幾乎捲不動。所以手指改成：沒選中的色條、縮圖、拍點格子，一滑就是捲畫面；先點一下選中，才拖得動。走位條也一樣：那個人選中了，他的走位條才拖得動。滑鼠照舊，按下去就拖。

電腦和 iPad 用同一套畫面。只有手指點的範圍、按鈕大小，在觸控螢幕上（`pointer: coarse`）偷偷變大，電腦上看起來不變。iPad 只顧橫拿；拿直的只叫教練轉回橫的。

一個小例外：場地左邊的「多選」「取消選取」只在觸控螢幕上（`pointer: coarse`）出現。它們是給沒有 Shift、Esc 的 iPad 用的；電腦用 Shift＋點、Esc、點場地空白處，擺著反而看不懂是做什麼的。

## Considered Options

- **照舊，碰到就拖**：滑鼠和手指一樣，不用解釋。但泳道排滿時找不到空白處可以捲。
- **按住不放（長按）才拖**：不用先選。但要等，也看不出來要等，手指一滑又容易誤拖。
- **電腦、iPad 兩套畫面**：各自最好用，但每改一次要做兩次、測兩次。

## Consequences

- 手指和滑鼠的拖法不一樣。說明書、提示要分開寫。
- iPad 不能蓋回原本的檔，存檔改用分享選單（存到「檔案」App 或直接傳給隊員）。

## 2026-11 更新：窄螢幕可以練習、記錄、看八拍表

瀏覽器實測發現，手機和直拿的 iPad 整頁被「視窗太窄」蓋住，教練沒辦法在場邊用手機記練習，隊員也沒辦法用手機看自己的八拍表。所以改成：

- **編輯**還是只顧橫拿的 iPad 和電腦。窄螢幕打開編輯畫面時，提示上有「回首頁」和「去練習」，不會被困住。
- **練習、記錄、總表**在窄螢幕上照常能用。
- **八拍表**在窄螢幕上能看（全隊或只看一個人），只能看不能改。

沒選「窄螢幕什麼都開放」：在手機上拖站位、拖色條，就算做得出來也很難用，還要多測一套畫面。
