# 第一版不做的幾件小事

規格（#15）的「地圖上沒討論到、開工時要先定的小事」列了四件。第一版這樣定：

- **復原（Undo／Redo）：2026-11 做了**，見 `docs/superpowers/specs/2026-11-03-formation-walk-design.md`。第一版沒做，因為刪東西都先確認、草稿自動存。紀錄在流程裡，復原時要把現在的紀錄帶過去，見 ADR 0006。
- **刪段、調段順序：做了（取代原本「第一版不做」）。** 在段設定裡「往前移／往後移／刪除這一段」。刪段照「刪除要先確認」同一套：段裡有動作、站位就列出來問。動作、站位跟著自己的段走；開頭那張站位跟著新的第一段（見 `docs/flow-file-format.md` 的「站位」）。
- **站位在時間上移動：2026-11 做了**，叫「挪站位」，見 `docs/superpowers/specs/2026-11-03-move-formation-design.md`。第一版只有插和刪。
- **位置的座標軸方向：已經定了**，寫在 `docs/flow-file-format.md` 的「位置座標」。
