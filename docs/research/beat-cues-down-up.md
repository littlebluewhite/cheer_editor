# down 與 up 的長度：拍數怎麼寫、工具怎麼設長度

研究紀錄，查核日期 2026-11-03。接續 [beat-cues.md](beat-cues.md)，那份已寫的不再重複。教練補充了三點：平常只喊 down、up；down、up 有長度，例如 cradle 可以「down 2 拍、up 1 拍」或「down 1 拍、up 1 拍」；High V 這類手臂動作固定 1 拍。這份查三件事：down／up 的拍數有沒有書面寫法、現有工具怎麼讓人設定「一件事佔幾拍」、平板上拖曳與點選的規範。

標記方式同 beat-cues.md：**已確認**（有原文）、**未確認**、**非官方**；推論會寫明「推論」；「查無」指在下方來源中查無。

## 結論

1. **「down 佔 2 拍」查無書面來源。** Varsity 的 cradle 教學只寫「One, two, down, up」：down 時 dip，up 時推上去，一個字對一個動作，沒寫各佔幾拍。「1-2 down, 3 up」這類寫法也查無。**未確認**。
2. **最接近的是 Varsity 的「like 1-2」**：coed toss 教學寫底層在「a designated count (like 1-2)」一起 dip。可以讀成「dip 佔 1、2 兩拍」，也可以讀成「數完 1、2 後 dip」，原文沒講清楚。原文已確認，意思**未確認**。
3. **規則裡寫到「幾拍」的只有停住多久**：喬治亞州 GHSA 2025 要求 secondary 和 coed 技巧到位後至少停「four (4) counts」。這是 hold 的長度，不是 down／up。已確認。
4. **紙本八拍表沒有「跨格」符號**：範例表把字寫在開始那一拍，後面格子空白，直到下一個字。沒看到破折號、箭頭、橫線或合併格。已確認，但只看了一份範例。
5. **常跟 down／up 一起出現的字**：dip、pop（「dip and pop」）、hit（規則用來指到位）、toss、drive、flick、catch、lock（指上層鎖腿，不是拍點）。這些字都沒寫佔幾拍。
6. **工具設長度有四種做法**：拖尾端（Ableton、Logic、Google 日曆）、點格子邊緣把下一格連起來（Logic iPad 的 Tie）、在長度條上按第 N 格（Novation Circuit）、從選單或旋鈕選數值（Ableton Set Length、Push）。連起來的格子畫成一條延伸的長條，或用連線的點表示（Logic）。
7. **WCAG 2.2 規定拖曳一定要有不用拖的做法**（2.5.7，AA），點選目標至少 24×24 CSS px（2.5.8，AA）。Apple 建議 iPad 控制項預設 44×44 pt、最小 28×28 pt；Google 依 Material 建議 48×48 dp。Apple 也要求拖放要有替代做法。已確認。

## 1. down／up 怎麼數

### 1.1 教學文章：一個字一個動作

| 來源 | 重點 | 寫了幾拍嗎 |
|---|---|---|
| [Varsity Stunting Basics][v-cradle]（2018-02-22，cradle） | spotter 數「One, two, down, up」；down 時底層一起 dip，up 時用腿和手推 | 查無 |
| [Varsity Coed Toss Drill][v-coed]（2018-02-22） | 在「like 1-2」的拍子一起 dip，接著 drives、toss；上層在最高點 flick | 只有「like 1-2」 |
| [Varsity Elite Stunts][v-elite]（2018-03-14） | 底層要「hesitate a split second」 | 用秒，不用拍 |
| [Omni Cheer：cradle][omni-cradle]（2012-11-06，非官方） | 喊「one, two, down, up」；這段叫「the dip and pop」 | 查無 |
| [Omni Cheer：elevator][omni-elev]（頁面標 2026-08-20，非官方） | 數法可以是「one, two, three, four」或「down, up」，由後保喊；上層要 lock 腿 | 查無 |

- 「cradle down 2 拍、up 1 拍」和「down 1 拍、up 1 拍」的差別，查無任何書面來源。**未確認**。
- 推論：Varsity 的「like 1-2」最像教練說的「down 2 拍」，但只有這幾個字，不能當成定義。

### 1.2 規則與教練研習資料

- [GHSA 2025 Checkbox Quick Reference][ghsa]（喬治亞州高中協會）：「Required Hold Count」是 secondary 和 coed stunts 到位後至少停 4 拍。已確認（下載 PDF 讀文字）。這是州協會，不是 USASF 或 ICU。
- [USASF 名詞表][usasf]（2026-05-18 更新）Twist/Twisting 條：「Once a stunt is hit」且有「clear and definite stop」。所以規則裡的 hit 是「到位並停住」。已確認。
- [ICU 名詞表][icu-g]：查無 Pop、Lock、Hit、Drive、Timing、Count 條目；Toss 有條目。已確認（經摘要工具）。
- [Varsity 2013 教練研習講義][v-2013]（各篇作者不同）：清手臂動作寫「Break down by 8-counts」「1-2-HIT」；清技巧寫「Breakdown each part of the skill (1-2 counts)」。已確認（下載 PDF 讀文字）。
- 推論：「1-2-HIT」是數 1、2，第 3 拍打到位，也就是手臂動作一拍到位，和教練說的 High V 佔 1 拍相符。原文沒解釋。

### 1.3 紙本怎麼寫佔好幾拍的事

| 寫法 | 出處 | 狀態 |
|---|---|---|
| 字寫在開始那一拍，後面空白，直到下一個字 | [範例八拍表][sample] 第 35 列：dip（1）、twist to retake/dip（3）、toss（5）、cradle（7） | 已確認（看原圖） |
| 停住寫一個字「hold」，放在開始停的那一拍 | 同上，第 11、12、14、25 列 | 已確認 |
| 同一格寫兩件事：「high v/dip」「hold/dip」 | 同上，第 17、32 列 | 已確認 |
| 數字範圍「1-2」 | 只有 Varsity 的「like 1-2」「1-2-HIT」 | 已確認原文 |
| 破折號、箭頭、橫線、合併格 | 範例兩頁、[CheerSounds][cs-help]、beat-cues.md 讀過的三份表單都查無 | 查無 |

- 這次把範例 PDF 轉成圖看，頁首有「NEW LEVEL MUSIC」標誌（beat-cues.md 寫出處不明）。是不是這家發布的，仍**未確認**。
- [Cali Coast Elite][cce]（健身房部落格，非官方）：「Hold」是停住「for the assigned number of counts」；「Hit」是在正確的拍子乾淨到位。

## 2. 工具怎麼設長度

只讀官方手冊與說明頁，沒有實際操作。版本會變，**要再核對**。

| 工具 | 怎麼設長度 | 怎麼顯示 |
|---|---|---|
| [Logic Pro for iPad：Step Sequencer 編輯模式][logic-tie]（版本選單最新 3.3） | Tie 模式：「Tap the right edge of a step」連到下一格，點左緣連到上一格；長度加上被連那格 | 頁面沒寫 |
| [Logic Pro for iPad：Step FX 步進調變器][logic-stepfx] | 把長條往右拖到蓋住下一格就連起來，可連好幾格；或點兩格編號之間的線來連或解開 | 長條延伸蓋住所有連起來的格；編號下方是「blue dots connected by lines」 |
| 同上（警告） | 捲動要在編號下方滑，不然會「accidentally create a number of ties」 | — |
| [Novation Circuit Mono Station 手冊 v1.2][circuit]：Gate View | 選一步，按長度條上的第 N 格，長度就是 N 步；「press the pad corresponding to the actual number of steps」；同一格重按每次少 1/6 步，按到第 6 次回到原值 | 上方 16 格長度條，亮幾格就是幾步 |
| 同上（即時錄音） | 打擊墊按越久，長度越長 | — |
| [Ableton Live 12 手冊][ableton-midi] 10.5.5 | 拖音符左右邊緣；Shift＋方向鍵一次加減一格；會對齊格線 | 長條 |
| 同上 10.5.9.6 | Duration 下拉選單選長度，按「Set Length」 | — |
| [Ableton Push 3 手冊][push] 6.1 | 按住步的 pad，叫出 Nudge、Length、Velocity，用旋鈕調 Length | — |
| [Google 日曆（電腦）][gcal-pc] | 點空白時段建立；「drag your mouse down the page」可拉長 | 時間格上的長方塊 |
| [Google 日曆（Android）][gcal-android]、[（iPhone、iPad）][gcal-ios] | 點空白時段建立；「tap and drag the top or bottom circles」改長度；拖整塊可移動 | 方塊上下各一個圓點 |
| [Apple 日曆（iPhone）][apple-cal] | 按住活動再拖到新時間，或拖「grab points」改長度；新增活動則按＋、在表單填起訖時間 | 方塊上下的拖曳點 |
| 啦啦隊、舞蹈 app（[CS 8-Count][cs-app]、[CheerCraft][cheercraft]、[mo-sim][mosim]） | 商店頁查無「一個標記佔好幾拍」；mo-sim 只寫可以「Edit scene lengths」，沒寫怎麼改 | 查無 |

- Apple 的 iPad 日曆說明頁這次只讀到目錄，上表用 iPhone 版。iPad 是否相同，**未確認**。
- 推論：這些工具都把長度存成「起點＋長度」。拖、點邊緣、選數字，改的都是同一個長度值，所以同一個資料可以同時給好幾種輸入方式。

## 3. 觸控與平板

| 來源 | 重點 |
|---|---|
| [WCAG 2.2][wcag22]（W3C 建議標準，2024-12-12）2.5.7 Dragging Movements，AA | 用拖曳完成的功能，都要能「by a single pointer without dragging」完成；除非拖曳是必要的 |
| [Understanding 2.5.7][u257] | 例子：滑桿可直接點軌道上的點；可排序清單點選後用上下按鈕；選取框可以「enable a mode, then click two opposite corners」。只給鍵盤替代不算符合 |
| WCAG 2.2 2.5.8 Target Size (Minimum)，AA | 目標至少 24×24 CSS px；例外：間距夠、同頁有等效控制、行內、瀏覽器控制、必要 |
| WCAG 2.2 2.5.5 Target Size (Enhanced)，AAA | 至少 44×44 CSS px |
| WCAG 2.2 2.5.1 Pointer Gestures，A | 多指或路徑手勢要能用單指、不走路徑完成 |
| [Apple HIG：Accessibility][hig-acc] | iOS、iPadOS 控制項預設 44×44 pt、最小 28×28 pt；有邊框的元件周圍約留 12 pt |
| [Apple HIG：Gestures][hig-ges] | Drag 的一般用途是「Move a UI element」；自訂手勢不能是重要動作的唯一做法 |
| [Apple HIG：Drag and drop][hig-dnd] | 「Offer alternative ways」完成拖放，例如用選單指令 |
| [Android 無障礙說明：Touch target size][a11y-48] | 依 Material 指引，可點元素至少 48×48 dp（約 9 mm），間隔 8 dp 以上 |
| Material 3 Gestures 頁 | 要 JavaScript 才能顯示，這次讀不到。查無 |

- 查無第一方文件直接比較「在格子上拖曳」和「點選」哪個在平板上比較好。
- 推論：時間軸縮小時，一拍一格可能小於 24 CSS px。那時要靠間距例外，或提供另一個夠大的控制（例如動作卡裡的長度按鈕）。

## 對設計的意義

以下全部是**推論**，要和教練確認。

- **主要做法用「挑長度」**：教練講的就是「down 2、up 1」，做成幾個 down／up 組合按鈕（例如 1+1、2+1、2+2），旁邊加 ＋／－ 微調。這和 Circuit「按第 N 格」、Ableton「Set Length」同一類，一點就好，符合 WCAG 2.5.7。
- **連點同一格加長只當捷徑**：連點看不出會到幾拍，點過頭要繞回來（Circuit 重按會循環）。不要當唯一做法。
- **拖曳拉範圍只當額外做法**：平板上捲動和拖曳容易打架，Logic 自己就警告會不小心連起來。若要拖，學 Google 日曆在兩端放圓點把手，把手至少 24 CSS px，最好 44 pt。
- **不用拖也能選範圍**：點起點那拍、再點終點那拍（WCAG 2.5.7 的「點兩個角」例子）。
- **佔好幾拍的 down 畫成一條長條**：從開始那拍延伸到結束那拍，字只寫在第一格，不要每格重寫 down。這和紙本「寫在開始那拍、後面空白」一致，又多了一條看得出長度的線（像 Logic 的延伸長條和連線點）。列印時照紙本，只寫第一格。
- **High V 這類手臂動作固定 1 拍**，不給長度控制；只有 down、up 有長度。
- **不要內建「cradle = down 2、up 1」**：查無標準。讓教練選，可以記住上次用的組合。

## 要問教練的問題

1. 「down 2 拍」是兩拍都在往下，還是第 1 拍往下、第 2 拍停在最低點？
2. down 和 up 中間會有空拍嗎？up 到位後的停住（hold）也要標長度嗎？
3. 會用到半拍（and）嗎？例如 down 1 拍半。
4. 除了 down、up，會不會也喊 pop、hit、toss、catch？這些也有長度嗎？
5. 紙本上 2 拍的 down 你怎麼寫：只寫第 1 格、兩格都寫，還是畫線？
6. 在平板上，你比較想點組合（例如「2+1」），還是用手指在格子上拉？
