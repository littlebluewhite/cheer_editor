# 立肩的兩個人：底下那位和肩上那位怎麼叫

研究紀錄，查核日期 2026-11-19。接續 `pyramid-layers.md`、`roles.md`。教練想在金字塔多一個任務角色，原話是「需要再多一個『站肩』或是『立肩』的角色，他的角色就是中層的底層」。這句話指誰還沒確定，所以兩種讀法都查：

- **讀法 A**：站在地上、肩上站著中層的那個人（立肩底下那位）。
- **讀法 B**：站在別人肩上的那個人（立肩上面那位；3 層金字塔裡就是中層）。

這裡只整理事實，不做決定。

標記方式：

- **已確認**：從原始 PDF 或網頁原文找到這句話，下方附引文。
- **部分確認**：有原文，但要靠推論才能套到問題上。推論會寫明「推論」。
- **未確認**：查不到原文。

「查無」都指「在下方來源中查無」，不代表沒有人這樣說。來源代號見文末。

## 結論

1. **立肩、站肩、肩立都是技巧或位置的名字，讀到的來源沒有一處拿來叫人。**「立肩的人」「站肩的人」「立肩手」「立肩人員」「站肩者」全部查無。技巧名和位置名的引文已確認。
2. **讀法 A（底下那位）沒有專屬名詞，所有來源都只叫「底層」。** 英文也只叫 base。10 個候選詞在台灣來源全部查無；「底座」只在大陸來源出現。已確認（引文），候選詞是查無。
3. **讀法 B（肩上那位）已經有名字：上面沒有再撐人時是「上層」，撐著 3 層時是「中層」。** 規則寫「中層人員」，英文是 middle layer、second layer base、Middle；台灣隊伍口頭也說「中層」。已確認。
4. **「立肩」和「站肩」在台灣都有人用，都是指技巧。** CTCA 同一份規則兩個都寫：「爬上立肩」（技巧名，1 次）和「站肩的位置」（位置，3 次）。台南市中學規則寫「肩立姿」「肩立」。大專規則三個詞都沒有。規則以外，寫「立肩」的有維基、個人部落格、校刊；寫「站肩」的有一個啦啦隊論壇的技巧名稱表。樣本太少，哪一個口語比較常用是**未確認**。
5. **英文 "second layer base" 指的是中層本人（讀法 B），不是讀法 A。** 教練說的「中層的底層」和這個英文字面上對得起來，這只是推論，不能當成教練的意思。
6. **大陸叫底座、尖子、后点，技巧名寫「站肩」；香港報導寫底層、中層、頂層。** 只做對照。已確認（大陸來源不是規則原文）。

## 已做的決定（2026-11-19，使用者）

1. **新角色是讀法 A**：站在地上、肩上站著中層的那位。
2. **名字叫「肩底」。** 這是編輯器自己取的名字，來源裡查無。
   - 不直接叫「立肩」「站肩」：那兩個是技巧的名字，一個詞只留一個意思。
   - 沒選「中底」：字面跟「中層」太像。
3. **肩底只指中層站在肩上的情況。** 中層站在手上時，下面的人還是底層。
4. **只有金字塔的任務角色選單有**，跟三層一樣。

CTCA 的兩個寫法對應同一個英文。[ICU 2026 規則][icu-26ch] Novice Stunts B.1 Exception 2：

> A walk up shoulder stand is allowed in the Novice Division if both hands of the top person are in contact with both hands of the base until both feet of the top person are placed on the shoulders of the base.

Novice Pyramids C.1.b Exception：

> Prep level top persons are not required to have both feet in the bases' hands if the top person is in a shoulder sit, flat back, straddle lift or shoulder stand.

所以「立肩」和「站肩」在 CTCA 都是 shoulder stand 的譯名，一個用在技巧名，一個用在位置。已確認。

### 解讀

- 規則裡三個寫法並存：立肩、站肩（CTCA），肩立、肩立姿（台南市）。大專規則不用這個詞。已確認。
- 規則以外讀到的來源：寫「立肩」的 3 個（維基、Allen Yang、淡江時報），寫「站肩」的 1 個（wwetw 論壇）。這不足以判斷口語哪個多。**未確認**。
- 沒有任何來源把這三個詞當成人的稱呼。這和 `GLOSSARY.md` 的「立肩是動作，不是角色」一致。

- 立肩底下那位在每個來源都只是「底層」。沒有來源替「上面站著中層的底層」另取名字。已確認（引文）；「沒有另取名字」是查無。
- 台灣教學和論壇會用別的方式細分底層，但都不是按「上面站誰」分的：

- Allen Yang 把「送三層的人」另外算，不算在立肩的底層裡：「限縮了其他人員的站立空間（如送三層的人）」。已確認原文；他和 `roles.md` 的「丟金字塔的人」是不是同一種人是推論。

### 解讀

- 肩上那位，上面沒有人時規則叫「上層」，高度是「2 層 2 段」（台南規則）。上面再站一個人，他就是「中層」。已確認。
- 台灣隊伍口頭把「中層」當人的稱呼用，而且和底層、上層並列。已確認（華視、Allen Yang、葉素汝等）。
- 華視報導裡教練解釋數字寫法：「所謂的111就是一個1代表一層所以三個1就是三層」。Allen Yang 也寫「2-2-1」「1-1-1」「1-1-2」，並說這些都是「以立肩作為主要支撐的金字塔動作」。所以在這些金字塔裡，中層就是站在底層肩上的人。「以立肩支撐」是原文，已確認；「中層＝立肩上面那位」是由此推得。

| 底層、中層、頂層 | 香港 | 三層的人 | 「啦啦隊一般分三層－底層、中層和頂層。Rachel便屬頂層，亦即『flyer』。」 | [香港01][hk01]（2018-09-05） | 已確認 |

- **底座、尖子、后点、前点是大陸用語。** 台灣規則和讀到的台灣來源都查無。
- 「站肩」在大陸也是技巧名，底下那位寫成「单底座」，沒有另外的名字。
- 香港報導的「頂層」在 `GLOSSARY.md` 是「三層」的 _Avoid_。
- [newton.com.tw 的「技巧啦啦隊」條目][newton] 是大陸百科內容轉成繁體，裡面的底座、尖子不算台灣用法。

## 6. 和 GLOSSARY 現有詞的關係（事實，不做決定）

| 詞 | 和現有 GLOSSARY 的關係 |
|---|---|
| 立肩 | GLOSSARY 已收，寫「立肩是動作，不是角色」。來源也都當技巧名。拿來當角色名，同一個詞會有兩個意思 |
| 站肩 | GLOSSARY 沒收。CTCA 用來講位置（「站肩的位置」），wwetw 論壇用來當技巧名。它和「立肩」是同一個英文的兩個譯名 |
| 讀法 A 的人 | GLOSSARY 現在叫「底層」。另外「主底」寫「單底層技巧裡唯一的那位底層也是主底」，照這句，單底層立肩底下那位現在算主底 |
| 讀法 B 的人 | GLOSSARY 現在叫「中層」（撐著三層時）或「上層」（沒有再撐人時） |
| 二層底 | 「二層」是「中層」的 _Avoid_。英文 "second layer base" 指中層本人，直譯會指到讀法 B |
| 中底 | 字面和「中層」「主底」「側底」都只差一個字。台灣來源查無 |
| 下層 | 和「底層」只差一個字。台灣來源查無 |
| 底座 | 大陸用語 |
| 塔底、塔基、肩底、立肩底、立肩底層、站肩底層 | 和現有詞沒有同字衝突。全部查無 |
| 支撐底層、金字塔支撐人員（Allen Yang 的說法） | 指底層。GLOSSARY 的「支撐」已經用在 bracer，意思不同 |
| 單底、雙底（wwetw 論壇的說法） | 「單底」是「單底層」的 _Avoid_，「雙底層」是「多底層」的 _Avoid_ |

## 要問教練的問題

1. 這個新角色是 1-1-1 最下面那位，還是中間那位？
2. 若是最下面那位：他和現在的「底層」「主底」差在哪裡？是不是只有肩上站著中層時才這樣叫？
3. 若是中間那位：他和現在的「中層」差在哪裡？是不是指上面還沒有三層、只是站在肩上的那個人？
4. 教練口頭說「立肩」還是「站肩」？指的是這個技巧，還是做這個技巧的某一個人？
