# 任務角色「肩底」和動作表單的人員清單

2026-11-19，跟使用者用 grill 定下來的（詞彙見 `GLOSSARY.md`，名字的研究見 `docs/research/shoulder-base.md`）。

## 肩底

- 固定任務角色多一個「肩底」：金字塔裡站在地上、讓中層站在自己肩上的底層。只有金字塔的選單有（跟三層一樣；
  已經是肩底的人換了大類，他自己的選單照列）。
- 在地上，算第 1 層；「有上層卻沒有底層」的提醒裡算底層。
- 流程檔第 13 版：舊版編輯器不認得肩底。升級時拿掉叫「肩底」的自訂任務角色，用到的人照留，變成固定的肩底。

## 固定任務角色的順序

分四群，選單裡群和群中間一條細線：

| 群 | 角色 |
|---|---|
| 撐人的 | 底層、主底、側底、肩底 |
| 被撐的 | 上層、中層、三層、支撐 |
| 保護的 | 保護、前保、後保、接者 |
| 其他 | 騰翻 |

自訂任務角色接在後面，前面也一條細線。

快捷鍵跟著角色固定（照上面的順序 1–9、0、Q、W、E，自訂接 R…）：每個大類同一個鍵都是同一個角色，
技巧沒有肩底，按 `4` 就沒反應（也不會交給頁面的快捷鍵）。

## 人員清單

- 動作有組：一組一張小卡（右邊欄夠寬時兩欄），卡片標題寫「第 n 組」，用組的顏色；沒分組的人在最後一張「沒分組」卡。
- 沒有組的動作：一樣的列，沒有卡片標題。
- 每列只有：名字（底色照性別）、任務角色選單、✕。拿掉全局角色的「底／上」圓點和每列的「第 n 組」。
- 拿掉「照組排」：永遠照組分。
- 卡片裡（和沒有組的清單）照任務角色的順序排（上面的表，沒有任務排最後，一樣的照加進來的順序）。改了角色那一列馬上移過去；
  按快捷鍵跳到的「下一個人」是改之前排在他下面的那個人。
- 列上的任務角色選單：普通的「底層」「上層」字淡一點，特別的角色（主底、肩底、中層、三層…）字深一點。
- 「Shift 點名字…」那一行照留。
