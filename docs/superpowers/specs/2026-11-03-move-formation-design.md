# 挪站位：拖縮圖或打拍子，改站位時間

設計文件，2026-11-03。名詞照 `GLOSSARY.md`（站位、站位時間、挪站位、走位、出發、到達）。這份推翻 `docs/adr/0003-v1-small-decisions.md` 的「站位在時間上移動：第一版不做」。

## 為什麼要做

站位時間是沒設走位的人到達、站好的那一拍。教練常發現站位放晚了：大家其實早就該站好。現在只能在新的那一拍插一張、刪掉舊的，可是插的那張會帶入「走到一半」的位置，全隊要重拖。

參考過的做法：Pyware 的隊形也是「走到的那一拍」；剪片軟體的「滾動」只動一個交界，前後的不動；Logic Pro 可以直接打小節和拍子移動片段。

## 要做的

1. **拖縮圖挪站位**：在站位縮圖列拖一張縮圖，放開就挪到那一拍。
2. **打拍子挪站位**：左邊欄名稱框下面有「站位時間」框，打拍子按 Enter 就挪過去。

## 不做的

- Shift＋拖讓後面的站位一起挪（漣漪）。
- 打「挪多少」（例 `-2`）。
- 雙擊縮圖跳出輸入框。
- 在站位縮圖列畫「在走」「站好」的色條。
- 動作、拍點跟著站位挪。

## 做了也算失敗的

- 挪站位改到任何一張站位裡的位置。
- 被挪的那張的前一張以前、後一張以後，有人的走法變了。
- 點一下縮圖（手抖一下）就挪到了。
- 被擋下來，流程還是有改到。
- 檔案格式要升版，或舊檔打開後有東西變了。

## 規則

被挪的站位叫 B，前一張叫 A，後一張叫 C。

### 能挪到哪

- 開頭那張不能挪。
- 新的站位時間要在 A 之後、C 之前，不能等於。B 是最後一張時，只要在 A 之後、流程結尾之前。所以站位的順序和號碼不會變。
- 可以挪到別段。時間吸到那一段的格子上：音樂段半拍，口號段 0.1 秒。
- 挪到原本那一拍：什麼都不改，不記復原。
- 被擋：流程不改，上方寫原因，例：「站位 3 要挪到站位 2（3-1）之後、站位 4（8-1）之前」、「開頭那張不能挪」。

### 走位怎麼跟

- **B 上自己設的出發和到達（A→B 這段）**：跟 B 一起挪一樣多的秒數，所以走的速度不變。
  - 挪完碰到 A，就夾在 A：走的時間變短。
  - 挪完不在格子上（例如跨到 BPM 不同的段），往前取到那一段的格子上，跟插站位一樣。
  - 夾完出發不早於到達，就當作沒設，用預設。
  - 寫多寫少由 builder 決定：只要每個人每一刻的位置跟「整組一起挪、再夾」算出來的一樣就好。
- **沒設的人**：照預設（到達 = B，出發 = B 往前一個八拍），本來就會跟著挪。
- **C 上的設定（B→C 這段）**：不改。計算時照舊夾在 B、C 之間；B 往後挪時可能被壓短，夾完出發不早於到達就當作沒設。
- **提示**：有人的走位比挪之前短（A→B 或 B→C 都算），上方提示「有 N 人的走位被壓短」，N 是人數。走太快的照舊標紅。
- 動作、拍點不動。例：後手倒拔的技巧在 6-1，站位挪到 5-1，大家 5-1 站好，6-1 才開始做。

### 拖縮圖

- 開頭那張拖不動。
- 按住縮圖拖一小段距離才算拖；沒超過就是點一下：選這張、跳過去，跟現在一樣。
- 拖的時候縮圖跟著滑鼠，吸到最近一格，縮圖上顯示新的站位時間（例：`5-1`、`12.3 秒`）。
- 放開才改。被擋：縮圖彈回原位，上方寫原因，跟拖色條一樣。
- 放開以後，播放頭跳到新的站位時間，這張保持選著。

### 打拍子

- 位置：左邊欄名稱框下面，標題「站位時間」。播放頭停在站位上才出現，跟名稱框一樣。
- 開頭那張：框是灰的，旁邊寫「開頭那張不能挪」。
- 寫法跟出發、到達欄位一樣：在 B 那一段只寫段內時間（`4-5`，口號段 `12.3`）；在別段時前面加段名（`口號 1 12.3`）。框裡顯示 B 現在的站位時間。
- 框下面一行小字寫能挪的範圍：「可以挪到 3-1 之後、8-1 之前」；B 是最後一張時寫「可以挪到 3-1 之後」。A、C 在別段時，前面加段名。
- 按 Enter 或離開框：套用。按 Esc：變回原本的，不套用。中文輸入法選字時按的 Enter、Esc 不算。
- 看不懂或被擋：框變回原本的站位時間，上方寫原因。
- 套用以後，播放頭跳到新的站位時間，所以框還在。

### 復原

- 一次挪站位（拖的或打的）算一步。

### 跟著變的地方

- 現在站位、站位縮圖列、八拍表、印出來的表，都照新的站位時間，不用另外做。
