# 成功率：練習時記 ✓ △ ✗，看每一組、每個環節穩不穩

設計文件，2026-11-04。名詞照 `GLOSSARY.md`（動作、組、環節、上法、中段、轉接、下法、整體、記號、一次、成功、小失誤、失敗、成功率、完成率、整次成功率、全上、分段練、辨識色）。
研究：`docs/research/success-rate.md`。原型在分支 `worktree-success-rate-design`，沒有進 main：`prototypes/phase-cues.html`（畫法 D）、`prototypes/success-rate-screen.html`（做法 1、2）。

## 為什麼要做

教練想知道每一組、每個環節（上法、中段、下法…）做得穩不穩，也想看每天有沒有進步。現在只能記在紙上。

參考過的做法：

- 台灣教練的「全上表」：每次全上記一張，一欄一組（欄名寫上層），成功的不畫，只標出錯的。
- HitRate（App）：一次點一下、大按鈕、可以復原、看每天的變化。
- 比賽規則和找到的工具都不把上法、中段、下法分開算。這裡分開算，是教練要的。

## 要做的

1. 動作可以打開「記成功率」，設定環節和組。
2. 環節可以標拍，跟拍點畫在一起：拍點格子、泳道、八拍表。
3. 新的「練習」畫面，分兩頁：「記錄」記分段練，「總表」看全部動作，也在這裡記全上。
4. 紀錄存在流程檔裡。

## 不做的

- 跟著音樂播放記全上（練習時不用這台 iPad 放音樂）。
- 印總表。
- 折線圖之類的趨勢圖；每天的變化用表格看。
- 記手位（像 high V）的成功率；手位是拍點，也不能當環節的種類。
- 兩台一起記、事後合併。
- 同一個動作裡，不同組記不同的環節。要不同，就拆成兩個動作。

## 做了也算失敗的

- 加、改、刪環節，改到拍點。
- 舊的流程檔打開後，有東西變了。
- 全上中途停了，後面沒做的動作被算成 ✓。
- 按上方列的「復原」，把剛記的紀錄也復原掉。
- 組換了人，舊紀錄沒問就混進新組合的成功率。
- 只練幾個環節的那幾次，被算進整次成功率。
- 上層被接進搖籃，被記成 △。
- 手抖點錯，沒辦法拿掉。

## 規則

### 記成功率（動作設定）

- 動作表單多一區「成功率」，裡面有開關「記成功率」，預設關。
- 打開時，照大類先填好環節，之後可以改：

  | 大類 | 先填的環節 | 怎麼算 |
  |---|---|---|
  | 技巧 | 上法、中段、下法 | 一組一起 |
  | 金字塔 | 上法、下法 | 一組一起，全部的人先放第 1 組 |
  | 拋投 | 整體「拋投」 | 一組一起 |
  | 騰翻 | 整體「騰翻」 | 每個人自己算，不分組 |
  | 跳躍 | 空的，自己加 | 每個人自己算，不分組 |
  | 舞蹈、其他 | 空的，自己加 | 一組一起 |

- 打開了，但一個環節都沒有：練習畫面不列出這個動作。
- 關掉時，這個動作有紀錄就先問，確定才清掉。

### 組

- 打開記成功率後，「人」清單每個人旁邊多一個「第幾組」。沒選組的人不算成功率。
- 組的名字自動叫「第 n 組＋組裡任務角色是上層的人」，例：「第 1 組 小美」。有好幾個上層就用名單上第一個；沒有上層就只叫「第 n 組」。
- 「從別的動作複製人」連組一起帶過來。
- 一組的人變了（加人、拿掉人、換人），而這組有紀錄：先問「保留舊紀錄」還是「清掉重算」。
- 改隊員名字（候補上場）而他有紀錄：也問。「保留」是只改錯字；「清掉」是真的換人了，清掉他在的每一組的紀錄（騰翻、跳躍的動作是清掉他自己的紀錄）。

### 環節

- 種類只有五種：上法、中段、轉接、下法、整體。可以再打名字，例：上法「延伸」。名字可以空著。
- 顏色：沒挑就用種類的顏色（上法青、中段石板灰、轉接金、下法紫、整體灰）。可以挑一個辨識色：動作辨識色能挑的 9 色，或石板灰。種類的顏色避開拍子 down 的藍、up 的綠。
- 加環節有兩種方法：
  - 在拍點格子選幾拍，跳出來的框多一列「環節」：選種類、打名字、加入；「清掉」拿掉這幾拍的環節。
  - 在成功率區的環節清單按「＋ 加環節」，不標拍。
- 標拍：
  - 只有音樂段的動作能標（跟拍點一樣）。
  - 環節之間不能重疊，中間可以有空拍。
  - 環節不分給誰，動作裡的人都一樣。
  - 環節跟拍點各管各的：拍點可以超出環節；加、刪環節不動拍點。
  - 動作變短切到環節、或換到口號段：跟拍點一樣先問，再切短或拿掉標的拍（環節留著，變成沒標拍）。
- 順序：標了拍的照時間排；沒標的排在後面，可以拖著換順序。
- 清單可以改名、換色、刪。刪有紀錄的環節要先問，確定才清掉那個環節的紀錄。
- 後來才加的環節：加之前記的那幾次，這一格是空的，不算。

### 環節怎麼畫（畫法 D）

- **拍點格子**：
  - 格子上面是環節清單：色塊、種類、名字、拍的範圍、範圍裡的拍點。
  - 格子裡，拍子那列上面多一列「環節」，用環節的顏色。
  - 標了拍的範圍，從上到下鋪同色的淡底，左右畫線。
  - 點一個環節，它那幾拍就亮起來。
- **泳道**：色條上多一條細細的環節（環節的顏色），底下鋪同色淡底。
- **八拍表**（黑白印）：每個動作的拍點上面多一行環節，用直線框出範圍。

### 練習畫面

- 最上面切換「編排｜練習」。練習分兩頁：「記錄」「總表」。
- 兩頁共用一個日期，預設今天；練完要補打時，改日期就好。

#### 記錄（原型做法 1）

- 這一頁記的都是分段練。
- 左邊：有打開記成功率的動作，照流程順序排。每個寫今天記了幾次、最弱的環節和它的成功率。
- 右邊：選到的動作，每組一張卡（騰翻、跳躍的動作是每人一張）。
  - 每個環節三顆大按鈕：✓ △ ✗。
  - 卡片上方切換「這次練：整個／只練幾個環節」，預設「整個」。選「只練幾個環節」時，點選要練哪幾個，沒選的環節按鈕變灰。
  - 照順序點。點到最後一個要練的環節，或點了 ✗，就自動存成一次；✗ 後面的環節空著。
  - 「刪掉上一次」：拿掉這組在這個日期的最後一次。
  - 上方列的「復原」只管編排，不會拿掉或救回紀錄；記錯了用「刪掉上一次」。
  - 卡片下面一排，列出這個日期的每一次，例：`✓✓△`、`✗··`。
- 下面：這個動作每天的成功率。
  - 一列一天，最後一列「合計」；一欄一個環節，最後一欄「整次」。
  - 大字是成功率，小字是完成率和次數。
  - 可以選看全部的組，或只看某一組。

#### 總表（原型做法 2）

- 篩選：
  - 期間：今天、最近 7 天、全部。
  - 練法：全部、只看全上、只看分段練。
  - 大字看：成功率或完成率。
- 每個有記成功率的動作一塊：
  - 一列一個環節，最後一列「整次」。
  - 一欄一組（騰翻、跳躍的動作一欄一個人），最後一欄「合計」。
  - 格子的顏色：90% 以上綠、75–89% 黃、75% 以下紅；沒有紀錄寫「—」。
- 點格子：右邊滑出這組、這個環節每一天的每一次，全上的那幾次有標出來。
- 「＋ 記一次全上」：
  - 每格先是 ✓。點一下變 △，再點變 ✗，再點回 ✓。
  - 一格變 ✗，同一組後面的環節變空的；改回來，後面回到 ✓。
  - 每個動作旁邊有「沒做（停了）」：按下去，整個動作變空的，不算進成功率（全上中途停了用）。
  - 按「存這次全上」才存；「取消」什麼都不存。

### 怎麼算

- 成功率 = ✓ ÷ 有打記號的次數。空的不算。
- 完成率 =（✓＋△）÷ 有打記號的次數。
- 整次成功率：只算整個做的次（全上都算整個做；中途 ✗、後面空著的也算）。每個環節都 ✓ 的次 ÷ 這些次。那一次之後才加的環節不看。
- 「合計」：把這個動作所有組（或所有天）的次數加起來算，不是把每組的百分比平均。

### 存檔

- 紀錄存在流程檔裡，跟著動作。環節、組、紀錄都是新欄位，格式要升一版；舊檔沒有這些欄位，就是沒有環節、沒有組、沒有紀錄，其他都不變。
- 流程檔傳給隊員，隊員也看得到成功率。
- 同一時間只有一台在記。兩台各記各的，合不起來。
- 草稿照樣自動存；iPad 存檔照舊走分享選單。

### 跟著要改的字

- 使用說明（`src/routes/guide/+page.svelte` 動作那一列）和 `src/lib/core/actions.ts` 開頭的註解，把動作寫成「一組隊員」，要改成「一群隊員」，免得跟「組」搞混。
- 「從別的動作複製人（連任務角色）…」改成「（連任務角色和組）」；使用說明的「整組帶進來」換個說法，不要用「組」。

另外發現、不屬於這次的：段設定的標題「拍子」（`SegmentSettings.svelte`，內容其實是 BPM 和第一拍），和使用說明裡幾處「對好拍子」，用的是一般的拍，跟拍點的「拍子」撞名。之後另外改。
